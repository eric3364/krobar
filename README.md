# Krobar

Krobar transforme un texte en visuel SVG : collez un paragraphe, l'IA propose
les meilleurs templates, vous choisissez une palette, vous exportez en SVG ou PNG.

## Stack

- React 18 + Vite + TypeScript
- Tailwind CSS + shadcn/ui
- Backend FastAPI externe (endpoint `/api/analyze`)

## Scripts

- `npm run dev` — démarre le serveur de développement
- `npm run build` — build production
- `npm run test` — lance la suite de tests
